# ShiftFlow

**ShiftFlow** — Flutter-приложение уровня production для учета смен и подтверждения выплат с ролевой моделью (Сотрудник / Администратор), чистым dark UI.

## Что я сделала

- Спроектировала и реализовала полный рабочий сценарий: создание смены -> проверка администратором -> подтверждение оплаты
- Реализовала ролевое поведение и разные пользовательские потоки для сотрудника и администратора
- Настроила локальное хранение данных и сохранение сессии (`SharedPreferences`)
- Построила статусную бизнес-логику (на проверке, подтверждено, отклонено, оплачено)
- Добавила опциональный remote-режим через `dart-define` (интеграция с endpoint)
- Подготовила проект к публичной публикации: без клиентских секретов и приватных данных

## Стек
**Flutter, Dart, HTTP, SharedPreferences, Intl, Material**

## Запуск
```bash
flutter pub get
flutter run
flutter run --dart-define=SHIFTFLOW_SHEETS_URL=https://example.com/api/shiftflow
```
