# ShiftFlow

Flutter-приложение для учета смен, проверки записей и контроля выплат без привязки к конкретному клиенту.

## Ключевые возможности

- Поток сотрудника: создание записи о смене, отправка на проверку, просмотр статусов.
- Поток администратора: проверка, подтверждение, отклонение и удаление записей.
- Локальные аккаунты и сессия между перезапусками.
- Локальное хранилище записей (SharedPreferences) с опциональной отправкой в удаленный endpoint.

## Публичная (безопасная) конфигурация

- Не храните реальные ключи, URL, логины и пароли в коде.
- Передавайте endpoint только через `dart-define`.
- Пример запуска:

```bash
flutter run --dart-define=SHIFTFLOW_SHEETS_URL=https://example.com/api/shiftflow
```

## Ожидаемый API для remote-режима

- `GET <endpoint>` -> `[]` или `{ "records": [] }`
- `POST <endpoint>` с `action: "create"` и `record`
- `POST <endpoint>` с `action: "updateStatus"` и полями `id`, `status`
- `POST <endpoint>` с `action: "delete"` и полем `id`

Пример POST:

```json
{
  "action": "create",
  "record": {
    "id": "123",
    "date": "22.04.2026",
    "fio": "Сотрудник",
    "description": "Выполненные работы",
    "rate": 850,
    "start": "09:00",
    "end": "18:00",
    "dayHours": 8,
    "nightHours": 1,
    "salary": 7862.5,
    "status": "На проверке",
    "project": "Проект A",
    "comment": "Комментарий"
  }
}
```
